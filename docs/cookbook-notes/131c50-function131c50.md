## What differed

This function replaces the backing buffer of a vector of non-trivial callable objects, destroying and deallocating the previous buffer before storing the new begin, end, and capacity pointers. An inline loop that reloaded the end pointer on every iteration produced a shorter function, and hoisting the end pointer gave the exact size but swapped the final stores to the end and capacity fields relative to the callee-saved register restore.

## Spellings tried that did not help

- Free function taking the vector pointer with an inline element-destruction loop reloading the end pointer each iteration.
- Free function or direct member function with a hoisted end pointer and direct member assignments to begin, end, and capacity.

Instantiate the toolset's vector over std::function with a stand-in argument type, and bind the private member with a CI hash line. The template gives the store order that the hand-written forms did not reach:
