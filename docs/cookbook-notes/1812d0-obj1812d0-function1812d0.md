## What differed

Comparing the three trailing 64-bit fields individually reversed the memory-versus-register comparison encoding relative to the target, while returning the boolean result of a 24-byte memory comparison directly caused the compiler to emit subtraction instead of equality comparisons.

## Spellings tried that did not help

- Comparing the three 64-bit fields one by one with left-hand member on the left of the inequality operator.
- Comparing the three 64-bit fields one by one with right-hand member on the left of the inequality operator.
- Returning the inequality test of `std::memcmp` directly as the return expression.

## Spelling that fixed it

Branch on the `std::memcmp` result and return explicit boolean literals so the compiler emits inline register-versus-memory equality checks:

```cpp
if (a_rhs->location28 != location28) {
    return true;
}
if (std::memcmp(&transform10, &a_rhs->transform10, sizeof(transform10)) != 0) {
    return true;
}
return false;
```
