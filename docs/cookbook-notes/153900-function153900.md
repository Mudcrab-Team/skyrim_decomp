## What differed

Direct `return` statements inside a five-case `switch` inverted the final case check, jumping to the last case and falling through to the default return instead of falling through to the last case and computing its constant via address arithmetic on the decremented switch value. A chain of `if` statements lowered to a shorter sequence with different branch layout.

## Spellings tried that did not help

- Direct `return` in every `case` with `default: return -1;` at the end.
- Direct `return` in every `case` with `return -1;` after the `switch`.
- Direct `return` in every `case` with `default: return -1;` placed first.
- A five-branch `if` chain returning constants directly.

## Spelling that fixed it

Assign a local result variable initialized to the fallback value, set it in each `case` with `break`, and return the local after the `switch` (also closed twin `0x153940`):

```cpp
std::int32_t result = -1;
switch (value)
{
case 0: result = 18; break;
case 1: result = 19; break;
case 2: result = 20; break;
case 3: result = 21; break;
case 4: result = 22; break;
}
return result;
```
