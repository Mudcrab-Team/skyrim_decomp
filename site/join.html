01 / What you need

Your game, a computer, a GitHub account.

Windows, macOS or Linux with Python 3.11+ and git. Your own Skyrim Special Edition $version from Steam (the helper checks the exact file). The measured macOS setup occupies about 5.1 GiB plus temporary space. Wine, LLVM and the pinned Microsoft compiler are installed for you, the compiler from Microsoft's own servers. See the platform and disk record for measured setup and local comparison results; live outside intake is unproven.

02 / Three commands

Set up, compare, submit.

Claim issues show functions and classes already taken by contributors and the project. The helper skips other people’s live batch and range claims.

  1. 1

    ./sr go

    Checks your machine, installs what is missing, proves the setup on a function already matched, picks a small unclaimed function, claims it on GitHub and creates its source file. It may need your SkyrimSE.exe path, Microsoft compiler licence acceptance, and GitHub account or fork setup; your system may also ask for your password or, on Apple silicon, to install Rosetta 2.

  2. 2

    ./sr compare

    Compiles your C++ and compares it with the function in your own copy of the game, on your machine. Repeat until it says PASS.

  3. 3

    ./sr submit --dry-run, then ./sr submit

    Runs the checks and opens a pull request with your source and a summary of hashes and counts. No game bytes ever leave your machine through this tool.

On Windows use .\sr.cmd in place of ./sr. With a coding agent: open it in the cloned repository and say “help me match one function; follow docs/contributing-agent.md”.

03 / After you submit

Your pass is checked again.

The project compiles and compares your source on two of its own machines, and a Reviewer checks that it is plausible source with honest provenance. Then the function counts as matched and the commit credits you. If not, the reasons come back on your pull request. The service is operated by the maintainer, has no promised turnaround and may take days. As of 2026-11-15 it has never processed an outside PR through acceptance; follow PR labels and comments for status.
