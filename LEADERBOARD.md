# Contributor leaderboard

Current accepted functions only; revocations leave the leaderboard. Each contributor gets one credit per function, including independently verified alternate submissions, so contributor totals can exceed project totals. Bytes are the sum of function sizes, not unique executable coverage. Credit is a recorded claim, not proof of authorship. Project agents use the recorded Drafter model or generating tool; missing attribution is shown as Not reported. Tiers begin at 10, 100 and 1,000 functions. CI hash passes alone earn no accepted-match credit.

Generated by `python3 tools/build_leaderboard.py` from `data/progress.json` and its accepted reports.
